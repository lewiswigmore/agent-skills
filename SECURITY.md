# Security Policy

## Reporting a Vulnerability

If you discover a security issue in any skill, please report it responsibly:

1. **Do not** open a public issue
2. Use [GitHub Security Advisories](https://github.com/lewiswigmore/agent-skills/security/advisories/new) to report privately
3. Or email the maintainer directly

We aim to respond within 48 hours and will credit reporters in the fix.

## Scope

Skills in this repository are documentation and configuration files (Markdown).
Security concerns typically involve:

- Malicious code examples that could be copy-pasted
- Links to compromised resources
- Advice that creates security vulnerabilities
